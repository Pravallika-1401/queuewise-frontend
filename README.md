# QueueWise — Frontend

React frontend for QueueWise Smart Queue Management System.

## Tech Stack
- React 18
- Tailwind CSS (responsive design)
- Axios (API calls)
- React Router DOM
- Context API (global state)

## Setup
```bash
npm install
npm start
```

## Features
- User registration and login (JWT)
- Live queue tracking
- Digital token generation
- AI-powered wait time estimates
- Admin dashboard (call next, skip tokens)
- Fully responsive — mobile + desktop
